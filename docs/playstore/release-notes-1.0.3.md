# 1.0.3 Release Notes

Play Console "What's new" copy for the 1.0.3 release (en-US).

## What's New

- Changed backup export to use Android's native share sheet, so you can send your backup directly to any app, cloud drive, or device
- Removed the "Last backup" time display, since it could no longer be tracked reliably with the share sheet
- Split Version and Build into separate rows in Settings
- Fixed inconsistent title sizing across the Home, Products, and Settings pages

Thanks for using Warranty Store!
