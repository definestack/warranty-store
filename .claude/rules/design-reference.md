# Design Reference Rule

- Always treat `docs/design/` as the single source of truth for any design or UI reference material (mockups, screenshots, style references).
- Before implementing or modifying any screen, component, or visual styling, check `docs/design/` for relevant reference material.
- If a relevant design reference exists in `docs/design/`, follow it per the fidelity requirements in the UI design rules.
- If no reference exists for the work being done, fall back to the "When no Sample UI is provided" guidance in the UI design rules.
